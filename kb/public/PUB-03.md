# Router lights explained

## QN-Box 3
- Power: green steady = on; off = no power (check the adapter and socket).
- DSL/Fibre: green steady = line connected; green blinking = connecting; off = no line signal.
- Internet: green = online; red = the line is up but there is no internet session.
- Wi-Fi: green = Wi-Fi on; blinking = data is being sent.

## QN-Box 4
- Status ring: white steady = everything works; white pulsing = starting up (up to two minutes after a restart);
  orange = connected to the line but no internet; red = no line signal.
- Wi-Fi button light: blue = both Wi-Fi bands on; off = Wi-Fi switched off with the button.
- A white ring while devices still get no internet can mean the router stopped handing out addresses.
  A restart usually fixes this.

## QN-Mesh Duo
- Main unit light: white = online; yellow = weak connection to the second unit; red = no internet.
- Second unit light: white = paired and good signal; yellow = move it closer to the main unit; blinking blue =
  pairing mode.
